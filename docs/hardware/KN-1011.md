## Capability probe (read-only)

POSIX/BusyBox script: `scripts/router-probe.sh`.

Не меняет iptables, policy routing, sysctl, пакеты и процессы. Missing tool → `NOT AVAILABLE`.

Windows runner (OpenSSH `ssh.exe`, не PuTTY; copy через `ssh cat`, без SFTP):

```powershell
.\router-smoke.ps1 -Mode Probe -Router <addr> -User root
```

Совместимые параметры: `-RouterAddress`, `-SshUser`, `-CredentialSource`.

Credentials только из:

- аргументов (`-IdentityFile` / `-CredentialSource` как путь к ключу)
- env / local gitignored `.env`: `BTKN_ROUTER`, `BTKN_SSH_USER`, `BTKN_SSH_IDENTITY`, `BTKN_SSH_PORT`, `BTKN_SSH_PASSWORD`
- SSH agent

Пароли в git не класть. `.env` в `.gitignore`. Password SSH идёт через `SSH_ASKPASS`, не через argv.

Сырой trace (gitignore): `.research-local/hardware/kn1011-probe-YYYYMMDD-HHMMSS.txt`.

Статическая проверка скрипта (из корня репозитория):

```text
go test ./docs/hardware
```

`router-smoke.ps1` без `-Mode Probe` остаётся каркасом smoke (exit 2). Secrets не коммитятся.
