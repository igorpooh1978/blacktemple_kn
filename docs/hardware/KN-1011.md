
## Coexistence

Development routers may have xkeen. Do not delete it. Do not use `/opt/bin/xray`. Ours is `/opt/blacktemple-kn/bin/xray`. Own ports, PID, chains (`BTKN_`), logs.

Production `blacktempled` never stops XKeen. Temporary XKeen stop is allowed only in the gated test harness (`router-smoke.ps1 -Mode Smoke` + `scripts/router-smoke-app.sh`) when **both** `BTKN_ALLOW_ROUTING_MUTATION=1` and `BTKN_ALLOW_XKEEN_STOP=1` are set. Cleanup is the BTKN namespace only (never a global `iptables -F`). The kernel harness `scripts/router-smoke-routing.sh` is not the R6-I app path.

## Capability probe (read-only)

POSIX/BusyBox script: `scripts/router-probe.sh`.

Не меняет iptables, policy routing, sysctl, пакеты и процессы. Missing tool → `NOT AVAILABLE`.

Collects IPv4 tables plus IPv6: `ip6tables -t nat|mangle|filter -S`, `/proc/net/ip6_tables_targets`, XKeen IPv6 names/targets (addresses redacted).

Windows runner (OpenSSH `ssh.exe`, не PuTTY; copy через `ssh cat`, без SFTP):

```powershell
.\router-smoke.ps1 -Mode Probe -Router <addr> -User root
```

Совместимые параметры: `-RouterAddress`, `-SshUser`, `-CredentialSource`.

`.env` search: worktree `.env`, parent directories, then sibling main repo `blacktemple_kn/.env` (worktree layout). `.env` is never committed.

Credentials только из:

- аргументов (`-IdentityFile` / `-CredentialSource` как путь к ключу)
- env / local gitignored `.env`: `BTKN_ROUTER`, `BTKN_SSH_USER`, `BTKN_SSH_IDENTITY`, `BTKN_SSH_PORT`, `BTKN_SSH_PASSWORD`
- SSH agent

Пароли в git не класть. `.env` в `.gitignore`. Password SSH идёт через `SSH_ASKPASS`, не через argv.

Сырой trace (gitignore): `.research-local/hardware/kn1011-probe-YYYYMMDD-HHMMSS.txt`.

## Gated routing smoke (harness only)

```powershell
.\router-smoke.ps1 -Mode Smoke
```

Without **both** `BTKN_ALLOW_ROUTING_MUTATION=1` and `BTKN_ALLOW_XKEEN_STOP=1` the runner prints `LIVE ROUTING SMOKE: NOT RUN` and exits 0 (not a failure).

When both gates are set, PowerShell `try/finally` copies the R6-I IPK, snapshots XKeen, starts OUR Xray through `blacktempled`, refuses Apply while XKeen is active, then may temporarily stop XKeen, applies production Hybrid capture for one LAN `/32` client (TCP REDIRECT + UDP TPROXY on 11820), then always: `netfilter-reconcile stop`, stop test OUR Xray, restore XKeen. Without both gates the runner prints `LIVE ROUTING SMOKE: NOT RUN` and exits 0.
