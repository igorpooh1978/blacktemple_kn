# web/

Preact + TypeScript + Vite + plain CSS.

Forbidden: React, Angular, Vue, Quasar, MUI, Bootstrap, Tailwind runtime, Rive, Lottie, custom font packs.

Production artifact is static `dist/` embedded into `blacktempled`. Node.js is not installed on the router.

Size gate: gzip(HTML+JS+CSS) ≤ 250 KB.

UI language: Russian. Main screen is Connect/Disconnect, not Xray JSON.
